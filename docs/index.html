配置即一切

站点、接口、直播、壁纸、WebHome —— 全在一个 JSON 里。

// tv api.json — 你自己掌控的来源 { "sites": ["152 个站点"], "lives": ["直播源已就绪"], "wallpaper": "http://…/wallpaper", "allowedOrigins": ["https://…"] }

手机打开网页，就能控制电视

同网段使用局域网管理页；跨网络使用你自己部署的 HTTPS 中转服务。两种方式都需要授权。

01 · 连接

局域网复制 App 管理地址。公网遥控默认关闭，先部署服务，再在被控设备中配置并开启。

02 · 配对

公网控制台输入设备生成的限时单次配对码；设备授权可撤销，不公开本地管理端口。

03 · 控制

搜索、推送播放地址、暂停、上下集、重播及读取播放状态。设备必须在线且具备可用播放器。

不提供公共遥控服务器，不开放远程安装、文件访问或登录态提取。查看自托管部署说明
